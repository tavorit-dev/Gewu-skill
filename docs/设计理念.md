## 命名由来

「格物」取自《礼记·大学》中的「致知在格物，物格而后知至」。

格物，意味着探究事物、求索其理；致知，则指向认知的深化与完善。

这一思想与格物 Skill 的设计理念相契合：面对技术文章，不急于绘图，而是先理解内容、探究原理、梳理关系，再将复杂的技术知识转化为准确、清晰的视觉表达。

## 产品理念

格物是一款面向技术内容创作的智能配图 Skill，服务于技术博客、微信公众号、技术文档、课程材料与开发者知识库等场景。

它不仅生成图形，更关注图形背后的知识理解过程：发现值得可视化的内容，提炼核心机制，选择恰当的表达方式，并验证最终图示的准确性与可读性。

**先格物，后成图；先求真，再求美。**

让技术原理看得见，让复杂知识更容易理解。
