# 交付前自检清单

## 内容层面

- [ ] 这张图**只讲一件事**，读完能说出一个明确结论
- [ ] 图注独立可读（读者跳过图只读图注，也知道这张图在说什么）
- [ ] 图注写的是「读者获得什么判断」，不是「这是 XX 流程图」
- [ ] 图里的数字标明了性质（示意值 / 实测值）
- [ ] 节点、连线、标签与规划一一对应，无错别字

## 落盘层面

- [ ] 图片在文章**同名目录**里，不是散在 `source/` 下
- [ ] 正文引用是**裸文件名**，无目录前缀
- [ ] `hexo clean && hexo generate` 已执行
- [ ] `find public -type f -empty` 输出为空
- [ ] `find public -type f | wc -l` 数量合理（正常约 97 个）
- [ ] `grep -o '<img[^>]*>'` 能看到实际数量的 `<img>`，不是字面量 `![](…)`
- [ ] 外部素材已在 `## 引用与致谢` 中逐项注明来源、作者、许可

## 动图专属

- [ ] 抽帧比对相邻帧 `motion > 0`（动画真的在动，不是静止的 GIF）
- [ ] 尺寸为 **2× 缩放**（1× 的文字会糊）
- [ ] 动画只用 CSS（`@keyframes` + `offset-path`），**没有** SMIL `<animate>` 或 JS 驱动
- [ ] 所有 `animation-duration` 整除全局 `--loop`，循环无缝

## 能力边界（本环境必读）

**本环境 `Read` 打开图片只返回 `[Image #N]` 占位符，拿不到像素；`analyzeImage` 不可用。**

因此：

- **做不到**：抽帧回读、目视检查文字是否糊 / 有无重叠 / 中文渲染是否正确
- **做得到**：尺寸、墨色占比、动画是否在动、文件非空（用 `ffmpeg` + `PIL`/`numpy`，命令见 SKILL.md）
- **交付时必须说明**：哪部分已验（程序化）、哪部分没验（视觉）。把视觉终检交给用户。

**不要把程序化校验通过说成「图没问题」。** 没验的部分就说没验。
